# IYUNGA SECONDARY WEBSITE

This project contains a clean, organized structure for the IYUNGA Secondary School website.

Project layout:

- `html/` - website pages in HTML
- `css/` - stylesheets and design tokens
- `js/` - JavaScript behavior and interactions
- `images/` - image assets used across pages

Each HTML page links to the shared stylesheet and script files, keeping layout and behavior centralized.
